# Codex / AI Agent Instructions

Before changing code, read:
1. `README.md`
2. `PROJECT_CONTEXT.md`
3. `ARCHITECTURE.md`
4. `.ai/AI_INSTRUCTIONS.md`
5. `.ai/CURRENT_STATE.md`
6. `.ai/TASKS.md`
7. `docs/api-contracts.md`
8. Relevant source files

## Hard rules
- Work only on the assigned task and owned module.
- Do not build the whole project unless explicitly assigned integration ownership.
- Do not modify another teammate's active module to make your task easier.
- Do not silently change a shared contract.
- Do not hardcode or commit secrets.
- Demo/simulated data must be clearly labelled.
- Prefer the smallest working implementation that satisfies the MVP.
- Do not add extra frameworks, databases, or sponsor APIs without a documented reason.
- Run the relevant code/tests before claiming a task works.

## Before coding
State the task ID, files to modify, contracts used, whether contracts change, and a short implementation plan.

## After coding
Report files changed, what now works, commands/tests run, known issues, and documentation updated.

Repository documentation overrides assumptions from earlier chat sessions.
